# Security Policy

## Supported Versions

Na ten moment wspierana jest tylko najnowsza, aktualna wersja projektu.

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |


## Reporting a Vulnerability

Bezpieczeństwo tego projektu traktujemy bardzo poważnie. Doceniamy Twoje wysiłki w celu odpowiedzialnego ujawnienia problemów związanych z bezpieczeństwem.

**Prosimy nie zgłaszać luk w zabezpieczeniach za pośrednictwem publicznych zgłoszeń (issues) na GitHubie.**

Zamiast tego, prosimy o wysłanie wiadomości e-mail na adres:
**akneth.studio@gmail.com**

Postaramy się jak najszybciej odpowiedzieć na Twoje zgłoszenie, aby potwierdzić jego otrzymanie i rozpocząć pracę nad rozwiązaniem problemu. Dziękujemy za Twój wkład w utrzymanie bezpieczeństwa tego projektu.
